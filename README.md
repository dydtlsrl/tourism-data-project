# Tourism Data Project

관광 데이터를 수집·분석하고 지역별 결과를 시각화하는 실습 프로젝트입니다.  
블로그 학습 과정을 따라 단계별로 구현하고, 진행하면서 내용을 보완합니다.

## 프로젝트 목표

- 서로 다른 관광 데이터의 특징과 역할 이해
- 관광 관련 데이터 수집 및 정리
- 지역별 검색 관심도·관광 수요·장소 정보 분석
- 분석 결과를 대시보드로 시각화

## 데이터 소스

| 데이터 소스 | 주요 데이터 | 활용 목적 |
| --- | --- | --- |
| NAVER Trend | 여행·축제·캠핑·맛집 등 주제별 기간 검색 관심도 | **관심도** 파악 |
| 한국관광공사 관광 수요 데이터 | 지역별 체류 강도 및 소비 강도 | **수요 강도** 파악 |
| NAVER Local | 관광지·맛집·카페·숙박의 이름·주소·위치 정보 | **장소 정보 및 지도 마커** 표시 |

> 세 데이터는 같은 관광 주제를 다루지만 서로 다른 질문에 답합니다.  
> Trend를 지역 데이터와 직접 JOIN하지 않고, 각 데이터의 분석 결과를 지역별로 필터링하여 대시보드에 함께 표시하는 방향으로 학습합니다.
